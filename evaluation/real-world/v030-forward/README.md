## 观察与边界

这次试用跑通来源发现、指定版本正文读取、近邻/gap 判断和有来源文稿产出。根代理核对了实际文件、GQA 原文定位和引用导出日志；没有用模型自评分声明性能提升。

共 8 项逻辑来源请求：宿主 web 的 5 项搜索/打开，来源脚本 3 次单请求获取。来源脚本获取 553601 字节；宿主 web 未暴露原始传输量，所以不能认证全程 8 MiB 上限，只能报告该缺口。逻辑请求数不是隐藏后端 HTTP 请求总数。

未深读所有最新决定性近邻、核验图表页面、实际导入引用管理器、开展实验或证明，也未建立专家确认的近邻全集。不能据此给出召回率、成功率或称为完整查新；HOLD 是这次材料边界内的行动判断。熟悉的历史论文可能存在模型记忆影响，三个案例不构成跨领域科研质量 benchmark。
