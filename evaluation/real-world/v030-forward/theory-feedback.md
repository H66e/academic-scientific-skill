# 引理失效后的理论研究决策

当前对**目标命题**的判断是 **HOLD**。用户报告某引理不成立，只能说明依赖该引理的旧证明尝试当前无效；即使引理有反例，也不自动构成目标命题的反例。这是依据用户描述的逻辑判断，尚未查看或独立核验命题、引理、旧证明与失败见证。

停止把旧证明作为“已证明”的依据，并标出所有依赖该引理的步骤；不据此淘汰整个研究方向。未调用外部来源，没有训练、数值实验或完成的新证明。

下一步按如下次序推进：

1. 固定目标命题的完整量词、定义域和假设，单独写出失败引理及其在证明中的用途。保留旧稿与错误定位，避免修补时悄悄改变目标命题。
2. 人工核验引理的失败见证：它是否满足引理的全部前提；错误是否来自结论、量词、边界情形或遗漏假设。若用户的反例不在前提范围内，重新判断引理是否真的失效。
3. 画出依赖链，确定后续实际需要的是引理的完整结论，还是一个较弱子结论。尝试证明所需弱化版本，或用替代引理/不同证明路径恢复推导。
4. 用同一失败见证逐项检查目标命题的前提和结论。只有满足目标命题前提且违反其结论的可核验反例，才能反驳该命题；“原证明到这里走不通”还不是反证。
5. 若只能证明增加前提后的版本，应把它作为明确缩小的新命题记录，不将其称为原命题已经证明。若提出替代证明，需逐一核验新的证明义务，而不是仅确认文档或代码可运行。

最有价值的下一份材料是目标命题与假设、失效引理原文、失败见证，以及第一次使用该引理的证明段落。当前没有这些具体材料，所以不能声称哪条弱化或替代路线一定成立。

决策范围与解除条件：

- 目标命题：HOLD，等待合法目标反例或新的有效证明。
- 旧证明路线：当前不能作为证明；局部修复或换路线均可研究。
- 如获得满足全部目标前提的反例：只在该版本及假设范围内判定目标命题为假，并考察必要的重构。
- 如获得有效新证明：仅在已证明的条件下更新结论；不外推到更强命题。
- 本轮没有科学实验结果；不引入GPU、数据集、训练预算或“跑提升”的要求。
