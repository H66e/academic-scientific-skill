# 基于真实论文的评估

本目录保存真实来源的有限语料试用及后续评估协议。用户请求是人为构造的测试请求，不是真实研究者项目；论文及所读章节是真实的。固定语料阅读不等于联网检索召回评估，不能据此宣称选题成功率。

当前输入见 [cases.md](cases.md)，实际答复与观察见 [results.md](results.md)。来源于 2026-10-05 读取的公开 arXiv HTML 相关章节，记录精确版本与定位；没有下载或复制完整论文。只引用源内容支持的事实，不把未读实验结果加入测试资料。

上述是 v0.2.0 的固定语料记录。v0.3.0 另有[实际来源获取与分页记录](v030-source-checks.json)及[独立新上下文检索、阅读与产出试用](v030-forward/README.md)。两者均明确实际调用与未测边界，不能将获取成功当作查新完备或专家认可。

后续按 [rubric.md](rubric.md) 增加实际项目。原始输入、真实调用、当时语料、工具范围、预算、原始输出、评估依据与失败同样保留；私有材料留在用户授权的本地项目，公开发布使用脱敏或可公开材料。

## 历史与前瞻评估

历史案例冻结当时可得来源，隔离后续论文及结论；即使不提供后续材料，也不能保证模型训练记忆未泄漏。因此历史试用不能当作纯盲预测，须注明限制。评价当时决定的依据，不因后来实验失败判定当时理应 KILL。

前瞻案例先保存初始判断和补证计划，再记录实际新增论文、专家反馈和 pilot。区分执行故障、科学反驳和无结论；以知识增益与决策质量为指标，不只看是否发表论文。先做少量可核查项目，再根据实际覆盖扩展，不设虚构的已完成案例数。

优化使用的案例和保留验证案例分开。同一案例反复用于改写后不再称为未见验证；本目录当前公开案例只能作为回归输入。没有独立专家或完整近邻集合时，将相应评价标为未测，而不生成假 recall、胜率或置信区间。
