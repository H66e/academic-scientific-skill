# 真实科研评价判据

先冻结研究范围、事实来源、工具预算、模型配置（未知则明确说明）和评价对象，再执行。每项给出观察、定位和缺口；未知用未测，不填零分。

| 维度 | 需要的证据与可比较量 |
| --- | --- |
| 技术近邻发现 | 专家确认的、声明为非穷尽的近邻集合；已找到与漏掉的工作、机制别名。只有给定语料时不报告外部检索 recall |
| 证据忠实性 | 判断到实际版本、段落、公式或图表的对应；虚构、误归因、摘要升级全文的次数 |
| 新颖性判断 | 相对近邻的具体差异、覆盖边界、误报重复与过度 distinct；记录专家分歧 |
| 可行性判断 | 已确认资源、主要未知与实际成本；不把估计当用户承诺 |
| 反证质量 | 测试能否区别主张与最强替代解释，控制与失效条件是否明确 |
| 行动价值 | 下一步是否有预算、预期信息量、停止和复评条件；导师或使用者能否据此行动 |
| 决策风险 | 无依据 GO、无依据 KILL、未知是否保留 HOLD；以当时证据评价，避免事后归因 |
| 版本与记忆 | 新证据能否重开判断，无关变化是否误触发复评，旧失败是否被永久套用 |

评估者尽量先读原始问题和证据，再形成自己的判断；随后与 skill 输出比较。独立上下文与独立专家分别记录，不因模型上下文分开就宣称专家认可。保留原始答复与不利结果，明确样本、覆盖和选样限制。
