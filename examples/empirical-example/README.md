# empirical record example

**SYNTHETIC EXAMPLE — NOT A REAL SCIENTIFIC CLAIM**

All papers, searches, evidence, budgets and reviews in dossier.json are fictional schema demonstrations. The example.invalid URL is deliberately not a real source. Do not import these records into a real research project.

This example illustrates empirical validation and a bounded GO pilot record. Supports is not a universal evidence gate: the candidate-specific relation and target explain how evidence motivates the question. Passing audit checks cannot establish the truth of any fictional statement.

Run from the repository root:

```text
python -B skills/ai-research-mentor/scripts/research_audit.py validate examples/empirical-example/dossier.json
python -B skills/ai-research-mentor/scripts/research_audit.py rank examples/empirical-example/dossier.json
```
